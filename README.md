# blissmom

유튜브 링크를 넣으면 자막을 분석해서 카드뉴스로 보여주는 웹앱입니다.

## 실행 방법

```bash
npm install
npm start
```

브라우저에서 `http://localhost:3000` 접속 후 유튜브 링크를 입력하면 됩니다.

## 동작 방식

- `/api/cardnews` (POST `{ url }`): 유튜브 oEmbed로 영상 제목/채널/썸네일을 가져오고,
  `youtube-transcript`로 자막을 가져와 시간대별로 묶은 뒤 키워드 빈도 기반으로
  각 구간의 핵심 문장을 뽑아 카드뉴스(제목 카드 + 본문 카드 + 마무리 카드)로 구성합니다.
- 자막(자동 생성 포함)이 없는 영상은 카드뉴스를 만들 수 없습니다.
- 프런트엔드(`public/`)는 카드 슬라이더 UI를 제공하며, 각 카드를 PNG 이미지로 저장할 수 있습니다.

> 참고: 이 저장소를 만든 샌드박스 환경은 보안 정책상 `youtube.com`/`ytimg.com`으로의
> 외부 네트워크 요청이 차단되어 있어, 실제 유튜브 응답으로 동작을 검증하지는 못했습니다.
> 일반적인 네트워크 환경(로컬 PC, 서버)에서 실행하면 정상적으로 외부 요청이 가능합니다.
