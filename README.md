# blissmom — 갓생맘 대시보드

인스타그램 계정 팔로워 성장을 추적하는 정적 대시보드입니다. 빌드 도구 없이
순수 HTML/CSS/JS로 만들어져 있어 파일만 열면 바로 동작합니다.

## 실행

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

`index.html`을 파일 탐색기에서 더블클릭해서 바로 열어도 동작합니다.

## 구성

- `index.html`, `styles.css`, `app.js` — 대시보드 화면과 로직
- `data/daily-log.js` — 일별 팔로워 수·콘텐츠 로그 (샘플 데이터, `window.DAILY_LOG`)
- `data/reports.js` — 월간 리포트 서술 부분 (`window.REPORTS`). 순증·평균 조회 등
  숫자는 전부 `daily-log.js`에서 실시간으로 계산되고, 이 파일에는 "한 줄 결론",
  "잘된 것" 같은 글로 쓴 내용만 들어 있습니다.

## 새 달 리포트 추가하기

1. `data/daily-log.js`의 `days` 배열에 해당 월의 일별 기록을 추가합니다.
2. `data/reports.js`에 `"YYYY-MM"` 키로 `headline`, `numbers`, `wins`,
   `topPosts` 등을 채운 객체를 추가하면 월간 리포트 탭에 자동으로 표시됩니다.
3. 항목을 추가하지 않으면 "아직 이 달 리포트가 없어요" 안내와 기본 통계만 표시됩니다.

## 화면 구성

- **일별 지표**: 기간 순증/일평균/최고 증가일 등 요약 카드, 팔로워 성장 그래프
  (호버 시 날짜별 수치 표시), 월별 순증 막대 그래프, 검색·월별·발행일 필터가
  달린 일별 로그 테이블
- **월간 리포트**: 월별 요약 통계 + (작성된 경우) 이달의 콘텐츠 하이라이트,
  한 줄 결론, 숫자로 본 이번 달, 잘된 것 / 아쉬운 점

`data/daily-log.js`의 샘플 데이터는 임의로 생성한 예시 값입니다.
실제 계정 데이터로 교체해서 사용하세요.
